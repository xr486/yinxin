- 日期：2026-08-14
- 页面：http://localhost/yixin/DocPLM.php（菜单：图文档 → 文档工作区）
- 账号：admin / 123456
- 演示数据：主目录 → WHTEST项目 → 20260814；文档「产品设计规范」(v2, 正常)、「升版演示文档」(v2, 已归档)

## 验证前须知

- **权限缓存**：如果之前登录过，需先登出再登录（scripts 表新增页面后 PageSecurityArray 会话缓存不刷新）。
- 左侧树为纯文件夹树；右键目录节点弹出操作菜单（新建子目录/重命名/删除）。

---

## 1. 登录与进入

1. 打开 http://localhost/yixin/ → 输入 admin / 123456 → 登录
2. 左侧菜单点击「图文档」模块 → 展开 → 点击「文档工作区」
3. 预期：出现左侧「文档目录」树（主目录 ▸ WHTEST项目 ▸ 20260814）+ 右侧文件区

## 2. 左侧目录树

| # | 操作 | 预期结果 |
|---|---|---|
| 2.1 | 点击「展开」「折叠」按钮 | 整树展开 / 收起 |
| 2.2 | 点击目录左侧 `+`/`-` 折叠符 | 只展开/收起该目录 |
| 2.3 | **右键**「主目录」→ 点「📁 新建子目录」 | 弹窗出现，父目录=主目录，输入名称点「创建」→ 树中出现新目录（当前目录展开状态保留） |
| 2.4 | **右键**刚建的目录 → 「✏ 重命名」 | 弹窗带原名称，改后保存 → 名称更新 |
| 2.5 | **右键**该目录 → 「🗑 删除」 | 目录下无内容 → 删除成功；目录下有内容 → 提示"不能删除" |
| 2.6 | 左键点击目录 | 右侧面板 **AJAX 局部刷新**（无整页闪烁）→ 显示该目录文档列表 + 左侧选中高亮 |
| 2.7 | 刷新浏览器 | 之前展开的目录保持展开（localStorage） |

## 3. 文档导入

| # | 操作 | 预期结果 |
|---|---|---|
| 3.1 | 选中一个目录 → 点工具栏「⇧ 导入」 | 展开 5 行上传区，每行有「文档名称 / 编码(自动建议 DOC-YYYYMMDD-NNNN) / 选择文件」 |
| 3.2 | 填名称+选文件（可一次传多个）→ 点「导入文档」 | 成功后顶部绿字提示"成功导入 N 个文档"，列表出现新文档，状态=正常，版本=v1 |

## 4. 文件列表展示

| 列 | 说明 |
|---|---|
| ☑ / 序号 / 图标 | checkbox、行号、文件类型 SVG 图标 |
| 状态 | 正常(绿) / 已归档(橙) / 已废止(红) / 已删除(灰) 标签 |
| 文件名称 | 含当前版本号 `[v2]` |
| 后缀 / 文件编码 / 大小 / 所在目录 / 创建者 | 基本信息 |
| 备注 | 文档属性中的备注 |
| 最近操作 | 该文档最近一次操作（如"升版"） |
| 操作 | 属性 / 版本 / 日志 / 预览(仅图片PDF) / 下载 |

## 5. 下载与预览

| # | 操作 | 预期结果 |
|---|---|---|
| 5.1 | 点操作列「下载」 | 文件直接下载 |
| 5.2 | 图片文件（jpg/png）点「预览」 | 全屏灯箱显示大图，点击任意处关闭 |
| 5.3 | PDF 文件点「预览」 | 新窗口打开 PDF |
| 5.4 | 工程文件（step/dwg） | 只有「下载」（无预览，需 CAD 软件） |

## 6. 版本管理（升版 / 历史版本）

| # | 操作 | 预期结果 |
|---|---|---|
| 6.1 | 勾选「产品设计规范」（正常状态）→ 点「↻ 升版」 | 弹窗选择新文件+版本备注 → 确认后顶部提示"已升版到 v3" |
| 6.2 | 点该行「版本」 | 弹窗列出 v1/v2/v3，当前版本标记绿色「当前」，任意旧版可下载 |
| 6.3 | 校验：已归档/已废止文档点「升版」 | 提示"只有「正常」状态才能升版" |

## 7. 状态管理（归档 / 反归档 / 废止 / 恢复）

| # | 操作 | 预期结果 |
|---|---|---|
| 7.1 | 勾选正常文档 → 点「📦 归档」→ 确认 | 状态变「已归档」(橙)，日志记录"归档" |
| 7.2 | 勾选已归档文档 → 点「♻ 反归档」 | 状态恢复「正常」 |
| 7.3 | 勾选正常文档 → 点「🚫 废止」 | 状态变「已废止」(红)，日志记录"废止" |
| 7.4 | 勾选已废止文档 → 点「↩ 恢复」 | 状态恢复「正常」 |
| 7.5 | 状态流转校验 | 已归档/已废止文档不能 删除/升版/归档/废止（后端提示）；正常文档不能 反归档/恢复 |
| 7.6 | 勾选「升版演示文档」(已归档) → 点「♻ 反归档」 | 状态变正常（正好用它验证） |
