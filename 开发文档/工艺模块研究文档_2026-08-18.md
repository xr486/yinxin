## 一、模块全景

MES 系统在「产品数据管理」一级菜单下有 5 个二级模块：图文档管理 / 物料管理 / BOM管理 / **工艺管理** / 任务管理 / 工作流管理 / 设置。

「工艺管理」下有 **9 个子菜单**（按用户截图与参考 MES 菜单树比对一致）：

| # | 子模块 | 参考 URL | 实体核心概念 |
|---|---|---|---|
| 1 | 工艺路线 | `/web/technology/craftRoute/index` | 一份「物料 + 工序清单 + 流转规则」的工艺文件，**绑物料** |
| 2 | 工艺模板 | `/web/technology/craftRouteTemplate/index` | 同工艺路线，**不绑具体物料**，可被多个物料引用（多对多关联产品） |
| 3 | 工序 | `/web/technology/process/index` | 最小加工单元（机加工/装配/检验 等），被工艺路线引用 |
| 4 | 工序类型 | `/web/technology/process/category/index` | 工序的大类（机加/装配/电镀/热处理…），工序上挂工序类目 |
| 5 | 工序组 | `/web/technology/processGroup/index` | 工艺路线中一组工序的逻辑分组（"工段"/"加工单元"），与工艺路线多对多 |
| 6 | 工步 | `/web/technology/workStep/index` | 工序内的具体动作步骤，挂图/视频/SOP |
| 7 | 工艺规程 | `/web/technology/workingProcess/index` | 「物料 + 工艺路线 + 工位」组合生成的制程单（生产执行入口） |
| 8 | 工艺规范标准 | `/web/technology/craftStandard/index` | 文档化的工艺标准（带版次/内容/附件），引用到工序或工步 |
| 9 | 工艺设置 | `/web/settings/technology/index` | 模块级参数配置（自定义字段、按钮、页签开关等） |

**核心业务关系**：

```
物料 (sf_item_no) ──1:N── 工艺路线 (craftRoute)  ──N:M── 工序 (process) ──N:1── 工序类型 (processCategory)
                            │
                            └── N:1 工艺目录(树形分类，craftRouteDir)
                            └── 1:N 工序组
                            └── 1:N 工步（通过工序间接关联）
                            └── N:1 工艺模板（template 字段）

工艺模板 ──N:M── 物料（多对多关联产品）
工艺规程 ──1:1── 工艺路线 + 物料 + 工位（生产执行态）
工艺规范标准 ──独立文档（可被任意工艺路线 / 工序引用）
```

## 二、各子模块详细字段

### 2.1 工艺路线（CRAFT_ROUTE）

**列表页搜索条件**：工艺名称 / 工艺编码 / 物料名称 / 物料编码 / 备注说明
**左侧树**：工艺分类（树形目录 craftRouteDir）

**列表表格列**：
- 工艺名称、编码、版本号、工艺类型（craftRouteDirName）、物料名称、物料编码、备注
- 可导出 EXCEL

**编辑页（3 个 tab，9 个页签配置）**：

#### Tab 1 基本信息
| 字段 | 名称 | 说明 |
|---|---|---|
| code | 工艺编码 | 必填，自动编码（CRAFT_ROUTE_CODE） |
| name | 工艺名称 | 必填 |
| parentNodeId | 工艺目录 | 树形选择 |
| executor | 工艺员 | 选择用户 |
| audit | 工艺审核 | 选择用户 |
| approved | 工艺核准 | 选择用户 |
| largeVersion | 大版本号 | 数字 |
| minorVersion | 小版本号 | .0 |
| productionFlowMode | 工单流转模式 | 下拉（自动/手动/扫码…） |
| remark | 备注 | |

#### Tab 2 下级工序（SUB_PROCESS）
- 工序表格：工序名称 / 工序编码 / 前置工序 / 工时(小时) / 工期(天) / 工位
- 通过「选择工序」从工序库多选
- 关联 API：`GET /web/technology/craftRoute/{id}/getProcessList`
- 流程图：`/web/technology/process/processFlowChartPage`（可视化流转图，可选）

#### Tab 3 关联工艺规范（STANDARD）
- 引用工艺规范标准文档（多选）

#### 其他页签（数据增强）
- WORK_IN_PROCESS 在制品：定义该工艺在制品参数
- MOULD 模具汇总
- TOOLS 工装夹具
- PARAM_SET 工艺参数设定（key-value）
- PARAM_OUTPUT 工艺参数输出
- PROJECT_EXPLAIN 工程注释
- BIND_ASSEMBLY 绑定产线

**自定义字段示例**（CRAFT_ROUTE 模块）：
三级人员审批 / 编写 / 批准日期 / 批准 / 校对 / 参考 / 测试1（TEXT/TEXTAREA 类型）

---

### 2.2 工艺模板（CRAFT_ROUTE_TEMPLATE）

字段同工艺路线，差异：
- **不绑具体物料**，改为 N:M 关联多个物料（"关联产品" tab）
- 列表多「创建人员 / 创建时间」两列
- 多了「下级工序组」tab

**适用场景**：标准工艺的复用（如"机加标准工艺"可被多种零件引用）

---

### 2.3 工序（PROCESS）

**列表列**：
- 工序名称、编码（名称动态切换为"工序名称"/"工序组名称"）
- 工序类目（categoryNameSave）
- 工装装备（deviceInfoType）
- 工价（processWages）
- 工价类型（processWagesType）：计时/计件
- 工时（timeHour，小时）
- 备注、创建人员、时间、更新时间
- 版本号（largeVersion）
- 工序组别（processGroup）—— 工序才显示，工序组不显示

**编辑字段**（参考工艺路线下级工序弹窗）：
- 工序编码、名称、工序类目、工装装备、工价/工价类型、工时、工序组别、备注
- 关联工步（在工序详情内引用工步库）
- 工艺参数（输入/输出）
- 关联文件（图片/视频/SOP）

---

### 2.4 工序类型（PROCESS_CATEGORY）

**最简字典表**：
- 一级分类（oneType）
- 创建时间

在工序编辑中作为下拉选择。**只有一级**（不嵌套），是"字典"非"树"。

---

### 2.5 工序组（PROCESS_GROUP）

字段同工序，但额外有「组别名称」用于工艺路线中"工段"维度。

---

### 2.6 工步（WORK_STEP）

**列表列**：工步名称、编码、类型、备注、创建人员、时间

**编辑字段**（3 个 tab）：
1. **基本信息**：工步编码（自动）、名称、工步类型（树形选择 workStepDir）、备注、图片
2. **关联文件**：图标 / 文件类型（DRAWING/SIP/SOP/NC/视频/打标/标签/其他） / 文件名 / 文件版本
3. **工步说明**

---

### 2.7 工艺规程（WORKING_PROCESS）

**列表列**：制程名称、编码、物料名称、工艺路线名称、制单时间、制单员、审核时间、审核状态

**编辑字段**（2 个 tab）：
1. **基本信息**：
   - 制程名称、制程编码（自动 WORKING_PROCESS_CODE）
   - 制单时间、制单人（只读）
   - 物料名称（带选择器）/ 编码 / 型号 / 尺寸（只读）
   - 绑定工艺路线（带绑定/解绑/查看按钮）
   - 备注
2. **可扫码换线工位**（activateStationList）

> **业务含义**：工艺规程是「生产执行入口」，选择物料 + 工艺路线后生成具体制程单。

---

### 2.8 工艺规范标准（CRAFT_STANDARD）

**列表列**：状态（archivedStatus）、规范编码、名称、版次、备注、创建人员、时间

**编辑字段**：
- 基本信息：工艺标准编码、名称、工艺标准类型（树形 craftStandardDir）、版次、关联工单、创建人员、时间、备注、内容（TEXTAREA）
- 关联文件

**支持归档/反归档**（status 字段）

---

### 2.9 工艺设置（TECHNOLOGY）

通过 `/web/define/system/all` 动态加载，是**元数据配置中心**：
- 模块字段开关
- 按钮配置
- 页签启用
- 自定义字段

实现上 = 系统级「设置中心」通用页，参数是 moduleCode=TECHNOLOGY。

## 四、yixin ERP 实施建议（v1 范围讨论）

> **重要**：参考 MES 是 SpringBoot + Vue + 动态字段引擎，重度自定义；yixin 是过程式 PHP+MySQL 的传统 ERP，**不能照搬 9 个完整子模块的全部细节**。建议分阶段实施。

### 4.1 数据库映射（基础表，v1 必须）

```sql
-- 1) 工艺目录（树形分类）
CREATE TABLE craft_route_dir (
    id INT AUTO_INCREMENT PRIMARY KEY,
    parent_id INT DEFAULT 0,
    code VARCHAR(50),
    name VARCHAR(100) NOT NULL,
    remark TEXT,
    sort_order INT DEFAULT 0,
    created_at DATETIME,
    INDEX idx_parent (parent_id)
);

-- 2) 工序类型（一级字典）
CREATE TABLE process_category (
    id INT AUTO_INCREMENT PRIMARY KEY,
    one_type VARCHAR(50) NOT NULL COMMENT '一级分类',
    created_at DATETIME
);

-- 3) 工序
CREATE TABLE process (
    id INT AUTO_INCREMENT PRIMARY KEY,
    code VARCHAR(50) UNIQUE NOT NULL,
    name VARCHAR(100) NOT NULL,
    category_id INT,                       -- 工序类型
    device_info_type VARCHAR(100),         -- 工装装备
    process_wages DECIMAL(10,2),           -- 工价
    process_wages_type VARCHAR(20),        -- 计时/计件
    time_hour DECIMAL(10,2),               -- 工时(小时)
    is_group TINYINT DEFAULT 0,            -- 是否工序组（0=工序，1=工序组）
    process_group VARCHAR(50),             -- 工序组别
    large_version INT DEFAULT 1,
    remark TEXT,
    created_by VARCHAR(50),
    created_at DATETIME,
    updated_at DATETIME,
    INDEX idx_cat (category_id)
);

-- 4) 工步类型（树形）
CREATE TABLE work_step_dir (
    id INT AUTO_INCREMENT PRIMARY KEY,
    parent_id INT DEFAULT 0,
    code VARCHAR(50),
    name VARCHAR(100) NOT NULL,
    sort_order INT DEFAULT 0
);

-- 5) 工步
CREATE TABLE work_step (
    id INT AUTO_INCREMENT PRIMARY KEY,
    code VARCHAR(50) UNIQUE NOT NULL,
    name VARCHAR(100) NOT NULL,
    dir_id INT,                            -- 工步类型
    image_url VARCHAR(255),
    remark TEXT,
    created_by VARCHAR(50),
    created_at DATETIME,
    INDEX idx_dir (dir_id)
);

-- 6) 工艺规范标准类型（树形）
CREATE TABLE craft_standard_dir (
    id INT AUTO_INCREMENT PRIMARY KEY,
    parent_id INT DEFAULT 0,
    code VARCHAR(50),
    name VARCHAR(100) NOT NULL,
    sort_order INT DEFAULT 0
);

-- 7) 工艺规范标准
CREATE TABLE craft_standard (
    id INT AUTO_INCREMENT PRIMARY KEY,
    code VARCHAR(50) UNIQUE NOT NULL,
    name VARCHAR(100) NOT NULL,
    dir_id INT,
    edition VARCHAR(20),                   -- 版次
    work_order_code VARCHAR(50),
    val TEXT,                              -- 内容
    archived_status TINYINT DEFAULT 0,     -- 归档状态
    remark TEXT,
    created_by VARCHAR(50),
    created_at DATETIME,
    INDEX idx_dir (dir_id)
);

-- 8) 工艺路线（头）
CREATE TABLE craft_route (
    id INT AUTO_INCREMENT PRIMARY KEY,
    code VARCHAR(50) UNIQUE NOT NULL,
    name VARCHAR(100) NOT NULL,
    dir_id INT,                            -- 工艺目录
    materiel_id INT,                       -- 物料ID（关联 sf_item_no.id）
    materiel_code VARCHAR(50),
    materiel_name VARCHAR(100),
    executor VARCHAR(50),                  -- 工艺员
    audit VARCHAR(50),                     -- 工艺审核
    approved VARCHAR(50),                  -- 工艺核准
    large_version INT DEFAULT 1,
    minor_version INT DEFAULT 0,
    production_flow_mode VARCHAR(20),      -- 工单流转模式
    is_template TINYINT DEFAULT 0,         -- 0=路线，1=模板
    remark TEXT,
    created_by VARCHAR(50),
    created_at DATETIME,
    updated_at DATETIME,
    INDEX idx_dir (dir_id),
    INDEX idx_materiel (materiel_id)
);

-- 9) 工艺路线工序（行，工艺路线 ↔ 工序 多对多）
CREATE TABLE craft_route_process (
    id INT AUTO_INCREMENT PRIMARY KEY,
    craft_route_id INT NOT NULL,
    process_id INT NOT NULL,
    sort_order INT DEFAULT 0,
    front_process_id INT,                  -- 前置工序
    man_hour DECIMAL(10,2),                -- 工时
    duration INT,                          -- 工期(天)
    stations_name VARCHAR(255),            -- 工位（多个逗号分隔）
    remark TEXT,
    INDEX idx_route (craft_route_id),
    INDEX idx_process (process_id)
);

-- 10) 工艺路线模板关联产品（N:M）
CREATE TABLE craft_route_template_materiel (
    id INT AUTO_INCREMENT PRIMARY KEY,
    craft_route_id INT NOT NULL,
    materiel_id INT NOT NULL,
    UNIQUE KEY uk (craft_route_id, materiel_id)
);

-- 11) 工艺规程（生产执行单）
CREATE TABLE working_process (
    id INT AUTO_INCREMENT PRIMARY KEY,
    code VARCHAR(50) UNIQUE NOT NULL,
    name VARCHAR(100) NOT NULL,
    materiel_id INT,
    materiel_code VARCHAR(50),
    materiel_name VARCHAR(100),
    craft_route_id INT,
    audit_status VARCHAR(20),
    create_date DATETIME,
    creator VARCHAR(50),
    audit_time DATETIME,
    remark TEXT,
    INDEX idx_route (craft_route_id)
);

-- 12) 工艺规程工位
CREATE TABLE working_process_station (
    id INT AUTO_INCREMENT PRIMARY KEY,
    working_process_id INT NOT NULL,
    station_id INT,                        -- 工位ID
    activate_type VARCHAR(20),             -- 扫码换线
    INDEX idx_wp (working_process_id)
);
```

### 4.2 菜单 & 权限（按 yixin 三级菜单机制配置）

`scripts` 表新增 9 条；`user_power` 配菜单可见；`www_users.modulesallowed` 补 1。

### 4.3 实施分阶段建议

**v1（最小可用，本周可完成）**：
- 工序类型（字典，10 行内）
- 工序（增删改查 + 列表）
- 工艺路线（CRUD + 关联工序 + 关联物料）
- 工艺模板（CRUD + 关联多个物料）

**v2（中等复杂度，下周）**：
- 工步（CRUD + 图片/文件占位）
- 工步类型（树形）
- 工艺规范标准（CRUD + 内容/附件）
- 工艺规范标准类型（树形）
- 工艺规程（CRUD + 选物料 + 选工艺路线）

**v3（深度集成，长期）**：
- 工艺路线多 tab（模具汇总/工装夹具/参数设定/参数输出/工程注释/绑定产线）
- 工艺路线流程图（processFlowChartPage 可视化）
- 工艺设置（动态字段引擎）
- 自定义字段系统
- 工艺规程扫码换线工位联动生产
