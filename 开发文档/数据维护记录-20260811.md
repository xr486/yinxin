# 数据维护记录（2026-08-11）

## 1. "料号名称"物料改名（未删除）

- 背景：sf_item_no 中 1346 条物料 item_name 为占位符"料号名称"，其中 941 条被库存流水（6534 条）、供应商关系（563 条）、盘点明细（7775 条）、工艺路线（262 条）等**真实业务数据引用**，直接删除会破坏业务模块。
- 用户决策：**改名保留**，不删除。
- 执行 SQL（纯 ASCII，直接 mysql -e 执行）：

```sql
UPDATE sf_item_no SET item_name = CONCAT('未命名物料-', item_no) WHERE item_name='料号名称';
```

- 结果：1346 条全部改为 `未命名物料-<编号>`（如 `未命名物料-20501600`），`item_name='料号名称'` 残留 0 条。业务引用不受影响（只改名称字段，不改编号）。
